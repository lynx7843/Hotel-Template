# Hotel Management System

This project is a **Hotel Management System** developed using **C# for Windows** with **Microsoft SQL Server** as the database.

The system is designed to simplify hotel operations by managing guests, rooms, reservations, and billing through a desktop application. All hotel data is stored securely in a SQL database, ensuring accuracy and easy retrieval.

## Features
- Guest registration and management  
- Room availability and reservation handling  
- Check-in and check-out processing  
- Billing and payment management  
- Database-driven data storage using SQL Server  

## Technologies Used
- C# (Windows Forms)
- Microsoft SQL Server

This application is developed for academic purposes, learning database connectivity in C#, and understanding basic hotel management workflows.
